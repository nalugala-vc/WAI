# Screenshots for README

Add these images before submitting to Weather-AI (used in the root `README.md`).

| Filename | How to capture |
|----------|----------------|
| `dashboard.png` | Open `/` on live site or `npm run dev` — full weather dashboard |
| `canopy.png` | Open `/farm` — canopy upload page |
| `mockup-iphone.png` | Open `/demo` → select **iPhone** tab |
| `mockup-android.png` | Open `/demo` → select **Android** tab |
| `mockup-ipad.png` | Open `/demo` → select **iPad** tab |
| `mockup-laptop.png` | Open `/demo` → select **Laptop** tab |

**Tips**

- Use a consistent browser width (1440px recommended for dashboard/canopy).
- On macOS: `Cmd + Shift + 4` → spacebar → click window.
- Crop to the device frame for mockup shots.

After adding files, verify images render on GitHub:

```
https://github.com/<user>/<repo>/blob/main/docs/screenshots/dashboard.png
```
